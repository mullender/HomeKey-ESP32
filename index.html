HomeKey-ESP32 installer

Flash HomeKey-ESP32 to an M5Stack AtomS3 Lite (ESP32-S3) over USB, then configure Wi-Fi in the same browser tab via Improv Serial. No cable-and-terminal, no captive-portal step.

Factory install erases the entire flash. Any existing HomeKit pairing, saved Wi-Fi credentials, HomeKey reader credentials, and stored core dumps on this board will be lost. This is intentional for first-time setup. If you're re-provisioning an already paired device, use the device's captive-portal / config-AP flow instead of this installer.
  1. Plug the AtomS3 Lite into a USB-C port on this computer.
  2. Put the board into download mode: press and hold the small reset button on the side of the AtomS3 Lite for about two seconds until the internal green LED lights up, then release. Per the M5Stack AtomS3 Lite documentation, this is the supported way to enter the ESP32-S3 bootloader.
  3. Click Install below and pick the port. The name typically starts with /dev/cu.usbmodem… on macOS or COM… on Windows.
  4. After flashing, the installer will prompt for your Wi-Fi SSID and password and push them to the device over the same serial connection. This takes ~15 seconds; the device reboots on success and joins your network.

Requires Chrome, Edge, or another Chromium-based browser on a desktop OS. Safari and Firefox do not support Web Serial and this page will show a compatibility notice instead of the install button.
