HomeKey-ESP32 installer

Pick the board that matches your hardware, then click Connect. The build embedded here is the same commit as the associated build-manifest.json.

Factory install erases the entire flash. Existing HomeKit pairing, saved Wi-Fi credentials, HomeKey reader data, and stored core dumps on the board will be lost. Intended for first-time setup or a full reset.
Generic images require post-provision configuration. Once Wi-Fi is set up via the flasher, open the device's web UI and pick the NFC reader type (PN532 / PN7160 / ST25R3916) and its GPIO pins. The AtomS3 Lite preset below ships pre-configured for the M5Stack Unit NFC and does not require this step.

ESP32-C6 is not offered here: the current image overflows its OTA slot. Tracked as a follow-up.

Requires Chrome, Edge, or another Chromium-based browser on a desktop OS. Safari and Firefox do not support Web Serial and this page will show a compatibility notice instead of the install button.
